# IEEE Access draft package

This directory is a draft submission package for the Research Article route of IEEE Access.

## Current manuscript direction

The manuscript evaluates whether temporal cortical representations generated by TRIBE v2 add information when analyzing within-video audience retention and viewing termination. The primary dataset is the owner-authorized YugsaTV Shorts analysis. KFN Shorts are used only as an auxiliary public-view and cross-channel transfer stress test.

The manuscript deliberately uses content-level language. TRIBE v2 outputs are predicted cortical representations used as model-derived content features; they are not measurements of viewer BOLD activity, psychological state, learning, military readiness, or individual behavior.

## Package contents

- `main.tex`: English IEEE Access manuscript draft.
- `HANDOFF_GUIDE.md`: concise package map, build instructions, and
  interpretation boundaries for the next researcher.
- `references.bib`: IEEE-style BibTeX sources.
- `reference_evidence_matrix.md`: claim-by-claim mapping from external claims
  to direct sources and from own results to internal evidence.
- `reference_search_log.md`: dated source-search, verification, and exclusion
  record for the bibliography.
- `reference_change_log.md`: bibliography and prose revision record.
- `reference_audit_report.md`: latest deterministic citation/BibTeX audit
  report. Recreate it with `python scripts/audit_ieee_access_references.py
  --root paper/IEEE_access --write-report` from the repository root.
- `ieeeaccess.cls`, `IEEEtran.bst`, and related template assets: copied from the supplied IEEE Access package.
- `figures/`: PDF copies of the selected aggregate-analysis figures plus the
  editable SVG source for Figure 1.
- `build_review_figures.py`: regenerates the review-corrected Figures 5--7
  from sanitized aggregate audit tables.
- `data/review_figure_provenance.json`: records the inputs, outputs, and hashes
  for those regenerated figures.
- `data/`: small aggregate source files used for the tables and narrative; private raw Analytics responses and raw media are excluded.
- `appendix.tex`: integrated Appendix containing feature definitions, audit tables, extended descriptive figures, and the reproducibility record.
- `data/submission_audit/`: CPU-only circular-shift, matched-control, and fair model audit outputs generated from the frozen aggregate tables.
- `IEEE_ACCESS_SUBMISSION_REQUIREMENTS.md`: official-regulation summary and package checklist.
- Temporary renderings, duplicated template files, raster figure previews, and
  LaTeX build logs are intentionally kept outside this cleaned handoff folder.

The reference audit is offline and checks cited-key coverage, unused entries,
duplicate DOIs, required metadata, placeholders, and evidence-matrix coverage.
It does not replace human judgment about whether a source directly supports a
claim; that judgment is recorded in the matrix and search log.

`figures/00_pipeline_overview.pdf` is Figure 1 in the manuscript. It is a
source-verified walkthrough of video `P9n3oy1kfGw`: representative complete
9:16 frames from the public military-Shorts corpus are shown alongside the
example video's audio envelope, persisted model-input text, cortical surfaces,
aligned five-second profiles and retention curves, grouped evaluation, and a
25-second review candidate. The representative thumbnails are display-only and
are not treated as the source frames for the example analytics.
Run `python paper/IEEE_access/build_pipeline_figure.py` from the repository root
to regenerate its PDF, editable SVG, and 600-dpi PNG. This requires the existing
private retention responses, verified result release, and local staged source
media; no inference or API collection is performed. Source hashes and numerical
checks are recorded in `data/pipeline_figure_provenance.json`.
Figures 2--7 present the retention envelope, cortical PCA, adjusted
associations, same-family Ridge feature-set comparisons, matched pattern-change
event/control contrasts, and cross-channel held-out transfer. Figure 5 uses
video-equal MAE and distinguishes grouped from chronological evaluation;
Figure 6 uses 92 matched pairs from 84 videos and a zero reference line;
Figure 7 uses held-out $R^2$ with a zero reference line and keeps the 194/2,312
training/test sizes visible. The two remaining extended-analysis plots are
retained as a single high-resolution composite in Appendix Figure 8.

The revision trace is in `REVISION_REPORT_KO.md`; unresolved author or source
questions are in `OPEN_QUESTIONS_KO.md`; build and source-to-figure mappings
are in `REPRODUCIBILITY_NOTES.md`.

## Build

From this directory:

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

If `latexmk` is unavailable, run `pdflatex`, `bibtex`, and `pdflatex` twice.
The included PDF is a layout-check artifact, not yet a submission file.
