# Reproducibility Notes

## Manuscript build

From the repository root, run:

```text
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The build uses the included IEEE Access class, IEEEtran bibliography style,
font assets, and figure PDFs. The resulting document is `main.pdf`.

## Regenerating selected figures

The following command regenerates Figures 5-7 and the corresponding provenance
file from the released aggregate audit tables:

```text
python build_review_figures.py
```

The script reads `data/submission_audit/fair_model_metrics.csv`,
`data/submission_audit/matched_pattern_change_control_summary.csv`, and
`data/cross_channel_transfer.csv`. It requires Python 3 with NumPy, pandas, and
Matplotlib. Other tables and figures in the manuscript are supplied as
artifacts rather than regenerated by this script.

## Analysis scope

The package contains sanitized metadata and aggregate analysis outputs. It
does not include raw media, raw owner-authorized Analytics responses, model
weights, runtime caches, or credentials. It therefore does not reproduce the
original TRIBE v2 inference or YouTube collection. Those activities are outside
the public package's reproduction scope.
